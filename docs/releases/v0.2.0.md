# Broadcast Monitor 0.2.0 — Settings page

No more editing `config.json` in Notepad.

- **Settings page** (top right of the dashboard): vMix and ScoreConnect addresses, audio thresholds and sources, NDI sources, YouTube, OpenStatsEngine and phone alerts. Changes apply the moment you press Save.
- **First launch opens Settings**, with a short welcome. The dashboard shows a reminder until you save once.
- Bad values are caught before they're saved, with a plain-English note under the field (e.g. "Just the address, like 192.168.1.20").
- Suggestions from what's live: vMix input names, NDI sources on the network, and the dashboard address for phone alerts.
- Passwords and keys (Google client secret, Pushcut/webhook URLs, Twilio token) can be entered or replaced but are never shown back.
- Anything you've written into `config.json` by hand is kept when you save from the page.
- The status bar stays visible across the top of the Settings page.

## Download

- **Windows:** `BroadcastMonitor-0.2.0-windows-x64.exe` — double-click it. If Windows warns about an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.2.0-macos.zip` — unzip, replace the old app, right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.2.0-linux-x64.tar.gz`

Existing settings in `Documents/Broadcast Monitor` are kept.
