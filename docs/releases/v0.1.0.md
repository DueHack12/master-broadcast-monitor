# Broadcast Monitor 0.1.0

First release. One page with a status bar across the top — green, yellow or red — watching:

- **vMix** streaming, program/preview, recording, fade to black
- **YouTube** receiving the feed, and LIVE vs. still in preview ("press Go Live"), stream health, viewers
- **Audio** clipping and sustained-low levels from vMix's meters
- **Scorebot** (Sportzcast ScoreConnect III): computer online (ping), feed connected, data flowing, right sport — without needing OSE
- **OpenStatsEngine** (optional): running, active game, receiving the feed
- **NDI** sources on the network
- Phone alerts through **Pushcut**, Twilio SMS or any webhook

## Download

- **Windows:** `BroadcastMonitor-0.1.0-windows-x64.exe` — double-click it. Windows will warn that it's from an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.1.0-macos.zip` — unzip, then right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.1.0-linux-x64.tar.gz`

Settings live in `Documents\Broadcast Monitor\config.json` (created on first start). See the README for setup.
