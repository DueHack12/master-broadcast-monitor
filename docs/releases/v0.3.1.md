# Broadcast Monitor 0.3.1: reliable NDI monitoring

NDI sources no longer flip between "seen" and "missing", or vanish when they're still there.

- **Fixed: discovery asked only one network.** On a computer with more than one network card, every discovery question went out on the same card, often not the NDI one. Sources only showed up when vMix or another NDI program happened to ask, which caused the flip-flopping. Each network is now asked properly. Loopback and unconfigured cards are skipped, and network changes are followed.
- **Fixed: false "went offline" messages.** A sender refreshing part of its announcement was read as it leaving.
- **Sources are checked before they're called offline.** A quiet source is asked directly, then its NDI port is tested. A source that's still running stays listed even if discovery goes quiet.
- **The NDI card shows what discovery sees:** networks searched, last answer, and how many other computers answer. A hint appears if nothing answers, which is usually Windows Firewall.
- **Settings → NDI:** choose which networks to search, and (under More options) how long before a source is called offline.
- **The Windows download is now always `BroadcastMonitor.exe`.** Windows Firewall remembers its permission by file path, so save updates over the old file in the same folder.

## If NDI sources from other computers still don't show

Allow Broadcast Monitor through Windows Firewall on **both Private and Public** networks: Windows Security → Firewall & network protection → Allow an app through firewall → Change settings. A broadcast network without internet usually counts as Public.

## Download

- **Windows:** `BroadcastMonitor.exe`. Keep it in its own folder (e.g. `C:\Broadcast Monitor`). If Windows warns about an unknown publisher: **More info → Run anyway**. When the firewall asks, tick **Private and Public**.
- **Mac:** `BroadcastMonitor-0.3.1-macos.zip`. Unzip, replace the old app, right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.3.1-linux-x64.tar.gz`

Your settings in `Documents/Broadcast Monitor` are kept.
