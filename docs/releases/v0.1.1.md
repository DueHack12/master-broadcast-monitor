# Broadcast Monitor 0.1.1

- **Mac:** fixed a bouncing "exec" icon labelled *bm-server* in the Dock while the monitor runs. The monitor now runs only in its Terminal window.
- No changes to monitoring or alerts.

## Download

- **Windows:** `BroadcastMonitor-0.1.1-windows-x64.exe` — double-click it. Windows will warn that it's from an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.1.1-macos.zip` — unzip, replace the old app, then right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.1.1-linux-x64.tar.gz`

Your settings in `Documents/Broadcast Monitor` are kept.
