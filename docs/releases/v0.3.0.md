# Broadcast Monitor 0.3.0: choose your YouTube channel

- **Pick the channel, not just the account.** New browser sign-in: Google asks for the account and then the channel, Brand Account channels included. The YouTube card shows which channel is connected, and **Switch channel** changes it.
- Signing in from a phone or another computer works too: paste the address Google lands on into the YouTube card.
- The code sign-in (google.com/device) is still there for single-channel accounts.

## Switching an existing setup

1. Google Cloud → APIs & Services → Credentials → **Create credentials → OAuth client ID** → type **Desktop app**.
2. Broadcast Monitor → **Settings → YouTube**: set the client type to **Desktop app**, paste the new client ID and secret, then **Save**.
3. Dashboard → YouTube card → **Sign in & choose channel**.

## Download

- **Windows:** `BroadcastMonitor-0.3.0-windows-x64.exe`. If Windows warns about an unknown publisher: **More info → Run anyway**.
- **Mac:** `BroadcastMonitor-0.3.0-macos.zip`. Unzip, replace the old app, right-click **Broadcast Monitor** → **Open** the first time.
- **Linux:** `BroadcastMonitor-0.3.0-linux-x64.tar.gz`

Your settings in `Documents/Broadcast Monitor` are kept.
